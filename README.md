# New Faculty Pages SPC

## Purpose

The new faculty page restructures the original faculty page for SPC into a well-organized profile page and profile edit page. The information for faculty is now styled to look more appealing and easier to read.

## Contents

The repository contains three html pages and a stylesheet including:

index.html - Page that organizes the campus's to find what faculty the user is looking for.

faculty-profile.html - Page that organizes the profile of the faculty with all of their information.

faculty-information-collection.html - Page that collects the faculty information for the faculty profile page. (Does not update at this moment)

style.css - The stylesheet for the html pages.

## How to view

1. On the repo page, click the green Code button

2. Download Zip file

3. Find the Zip file in your files (usually in downloads) and unzip the file

4. Open the unzipped folder, locate the file named index.html, and double click or open with whatever web browser you use.

Once open you will see the campus page, navigate using the top bar by pressing any of the three options on the right side.
