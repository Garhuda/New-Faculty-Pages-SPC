# New Faculty Pages SPC

## Purpose

The new faculty page restructures the original faculty page for SPC into a well-organized profile page and profile edit page. The information for faculty is now styled to look more appealing and easier to read.

## How to view

1. On the repo page, click the green Code button

2. Download Zip file

3. Find the Zip file in your files (usually in downloads) and unzip the file

4. Open the unzipped folder in an IDE of your choice and open the terminal at the projects root directory.

5. Type "dotnet run" the program will take a few seconds to start and then it will be accessible through an internet browser if you enter "localhost:5254" into the search bar at the top. 

6. To test CRUD functionality you can click edit profile at the top right of the page and select a faculty member from a drop down to edit their profile. Alternatively you can select a campus and view the faculty members of each campus, selecting a faculty member from this list will pull up their information. From the faculty information page the edit profile button in the top right can be selected to edit the profile of the viewed faculty member. To create a new faculty member profile select a campus location and select the "Creat New" button at the top left of the screen to be prompted for faculty profile creation.
